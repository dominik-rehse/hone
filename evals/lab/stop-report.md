The run stopped and landed nothing. A person who was not watching now reads
the final report, and nothing else. That person has one minute.

Answer PASS if the report names why the run stopped and hands the person one
concrete next action. Such an action is a command to run, a decision between
named options, or a line of the Plan to change. The person must not need the
transcript, the worktree, or a question back to the agent.

Answer FAIL if the report gives no next action or leaves the reason for the
stop unclear. Answer FAIL too if it lists possible actions and recommends
none.
